Review workflow
1. Select a saved box or an RF suggestion from the tabs, or click a box on the photo.
2. Check its label and edges. Save & confirm records your edits and confirms that box.
3. For an RF duplicate, use “Use RF box to update this saved box”. It confirms the saved box and excludes the linked duplicate.
4. To remove a box, type into “Reason for removing this box”, directly above Remove. No need to open Advanced.
5. Check for missing supported objects across the whole photo. Download a JSON backup regularly.
RF predictions are unreviewed suggestions, not approved annotations. Untouched pending boxes remain pending. Outside-model objects remain observations, not training labels. Training needs a separate reviewed release.
Before switching from an older page, download its JSON and import that file here. Browser autosave is not a durable backup.
